# X 投稿案 2026-10

`node build/gen-x-posts.mjs` が生成した。設計は [x-account-plan.md](../x-account-plan.md)。

## 使い方

1. X をブラウザで開く。**予約投稿はブラウザ版でしか使えない**（アプリからは設定できない）
2. 下のコードブロックをそのままコピーして投稿画面に貼る
3. カレンダーのアイコンから日時を指定して予約する

文字数は X の重み付け（全角 2・半角 1・URL は一律 23）で数えてある。上限は 280。

**B・C・D 型は空欄で出る。** 判断が要るので Claude に書いてもらう。その際は
このファイル末尾の「候補データ」だけを渡せばよい（科目トップの HTML は読ませない）。

**あわせて新刊の調査も頼む。** 手順は次の節にある。**調査を先にやること。**
新刊が見つかると F 型の枠が増え、その分 A 型が減るため、後からだと作り直しになる。

## 新刊調査（Claude がやる）

**B・C・D 型を書く前に、まずこれをやる。** 新刊が見つかったら F 型の枠が
増え、その分 A 型が減るので、順番を逆にすると作り直しになる。

### 手順

1. 下の出版社の新刊ページを見る。あわせて検索でも拾う（両方やる）
2. 見つけた本が下の「収録済みの出版社」の冊数に照らして未収録かを確かめる。
   判断がつかないものはサイトの検索（`assets/js/book-index.js`）で書名を引く
3. 掲載する本を `build/data/new-books.json` に足す。**必須は id・subject・
   name・official・pub・year・stage の 7 つ**
4. **難易度・到達目安・強み・注意点・向いている人は書かない。** 現物を
   読んでいないため。`provisional: true` を立てて「評価準備中」で出す
5. 再生成する

```bash
node build/apply-new-books.mjs
node build/generate-books.mjs && node build/generate-index.mjs && node build/generate-picks.mjs
node build/generate-routes.mjs && node build/generate-articles.mjs && node build/generate-search.mjs
node build/apply-count.mjs
node build/generate-sitemap.mjs
node build/gen-x-posts.mjs <この月> --force   # F 型が入った状態で作り直す
```

`--force` で作り直しても **A 型の中身は変わらない**（used.json の byMonth が
この月の分を覚えているため）。安心して流し直してよい。

### 見つけても掲載しないもの

- 大学受験以外（小中学・高校入試・英検などの資格・専門学校・大学院）
- 改訂版のうち、**同じ本が既に収録されているもの**（版が変わっただけなら既存の year を直す）
- 赤本・青本などの大学別過去問（毎年出るうえ、収録済みの枠で足りている）
- 学校専売で一般に買えないもの（書影も取れず、読者が入手できない）
