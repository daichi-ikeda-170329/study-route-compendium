# QA 報告書のひな形

`docs/qa-report-YYYY-MM-DD.md` として複製して使う。

**書かないこと。**

- **Playwright の WebKit を「Safari 実機」と書かない。** 同じエンジン系統だが別物で、
  実機の Safari で起きることを必ず再現するわけではない。実機を触っていないなら
  「実機は未実施」と書く。
- 実行していない検査を「通った」と書かない。実行できなかったなら
  **できなかったと書く**（環境が無い・権限が無い・時間が足りなかった）。
- 個人の受験情報（志望校・学部・偏差値・完了教材）を screenshot やログに残さない。
  再現手順に書く必要があるときは、架空の値に置き換える。
