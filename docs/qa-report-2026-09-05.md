## 途中で落ちて、直したもの

| # | 内容 | 由来 | 対応 |
|---|---|---|---|
| 1 | `Escape` で大学候補が閉じない（Firefox） | **検査の書き方の誤り** | 候補は DOM から消えるのではなく `.open` が外れて隠れる。件数ではなく `aria-expanded` と見え方で確かめる形に直した（既存の `e2e/flows.spec.mjs` と同じ見方） |
| 2 | 書体の取得失敗が JS エラーとして出る（Firefox） | **第三者**（`fonts.gstatic.com`） | `THIRD_PARTY_NOISE` に `downloadable font:.*fonts\.gstatic\.com` を足した。**gstatic のものだけ**に絞ってあるので、自サイトの読み込み失敗は隠れない |
| 3 | `pageerror: undefined`（WebKit / Firefox） | **第三者**（AdSense） | 下に詳しく書く |

### 3 の切り分け

`RT_DEBUG_ERRORS=1` を付けて素の中身を採ったところ、2 通りあった。

```
[pageerror] msg="undefined" stack=""
[pageerror] msg="undefined" stack="uncaught exception: undefined
    at dk/</f.onerror (https://pagead2.googlesyndication.com/pagead/managed/js/adsense/…)"
```

どちらも **AdSense が Error でない値（`undefined`）を投げたもの**。
stack が付いているほうは既存の `googlesyndication` の型で落ちるが、
WebKit の側は stack が空で、どこから来たかを名指しできない。

そこで **「message が空か `undefined` / `null` で、かつ stack も空」** のときだけ数えない
規則を足した。この形は直すための手がかりが 1 つも無い。

**自サイトのエラーが隠れないことを確かめてある。** 3 ブラウザで自サイトのスクリプトから
`throw undefined` を起こしたところ、WebKit と Firefox では stack が付き、規則に掛からず
拾われた。Chromium では stack が空になるため同じ規則で落ちるが、Chromium の第三者ノイズは
ドメインの型ですでに捕まえているので、この規則が要るのは WebKit だけ。
限界も `e2e/helpers.mjs` のコメントに書いた。
