青チャート vs Focus Gold — 到達点が同じ2冊を分けるもの

徹底比較 の記事

公開 2026-09-09 ルート大全 編集部

数学の参考書で最も多く並べて語られるのが、青チャートとFocus Gold（フォーカスゴールド）です。結論を先に書くと、この 2 冊の到達点はほとんど変わりません。それでも選択に迷うのは、到達点以外のところが違うからです。この記事ではその違いだけを見ます。

この記事の内容

  1. まず数字を並べる
  2. 違い1 — 前から通したときの設計
  3. 違い2 — 解説の書き方
  4. 違い3 — どこで買えるか・情報の多さ
  5. 結局どちらを選ぶか

難易度と到達目安はほぼ重なります。「どちらが上か」を探しても答えは出ません。判断の軸は、始める時期・学校の配布・解説の読み心地の 3 つです。

違い1 — 前から通したときの設計

Focus Goldは、マスター編からチャレンジ編・実践編へと段が上がる構成になっています。1 冊のなかで入試応用レベルまで進む設計なので、最後まで通せば網羅系のあとに置く演習書を 1 段省ける形になります。

青チャートは例題・練習・演習問題という層の作りで、最上位の層まで含めても難易度の上限は Focus Gold のチャレンジ編ほど上には伸びません。そのぶん上の層を切り捨てて例題だけに絞る運用がしやすいという利点があります。

ここから、時期による使い分けが出てきます。

  • 高 1・高 2 から始める — 通しでやる時間があるので、Focus Gold の設計が生きます。
  • 高 3 から始める — 全部は通せません。例題だけに絞りやすい青チャートのほうが運用しやすくなります。

違い2 — 解説の書き方

Focus Goldは例題の前に「Focus」として考え方の方針を置きます。解く前に何を考えるかが文章で書いてあるので、独学で読む場合の負担が下がります。

青チャートの解説は簡潔で、行間を読者が埋める前提です。学校で解説を受けられる環境なら問題になりませんが、完全に独学で進めると詰まる箇所が出ます。

ただしこれは、青チャートの解説が不足しているという意味ではありません。同じページ数で扱う問題数を確保するための設計判断です。読み物としての厚みを取るか、参照のしやすさを取るかの違いになります。

配布されている本が最優先

学校でどちらかが配られているなら、配られたほうを使ってください。網羅系を 2 冊持つ意味はほとんどありません。手元にある本を最後まで通すほうが、乗り換えるより確実に速く終わります。

違い3 — どこで買えるか・情報の多さ

青チャートは採用校が多く、使い方の情報も多く出回っています。進め方に迷ったときに参照できるものが多いのは、独学では小さくない差です。

Focus Gold（フォーカスゴールド）は学校採用が中心の本ですが、個人でも買えます。出版元の啓林館が WEB ショップで販売しており、解答は全問付属すると案内しています。書店では大型店を中心に店頭に置かれています。

「学校で配られないと手に入らない」と思って候補から外す必要はありません。ただし小さい書店には置いていないことが多いので、手に取って解説の読み心地を確かめたいなら、大型書店か出版元の WEB ショップを当たることになります。

結局どちらを選ぶか

判断はこの順で付きます。

  • 学校でどちらかが配られている → 配られたほう。ここで終わりです。
  • 高 1・高 2 で、時間をかけて 1 冊を仕上げたい → Focus Gold。チャレンジ編まで進めば、次の演習書を 1 冊減らせます。
  • 高 3 から始める・例題だけに絞りたい → 青チャート。情報が多く、層を切って使う運用がしやすい構成です。
  • どちらも重いと感じる → 基礎問題精講に落とします。判断の材料は網羅系はどれを選ぶかにまとめました。
