リスニングはいつ始めるか — 対策本の選び方と毎日の回し方

科目別ルート の記事

公開 2026-09-08 更新 2026-09-09 ルート大全 編集部

共通テストの英語は、リーディングとリスニングという 2 つの試験に分かれています。換算の比率は大学ごとに違いますが、リスニングを捨てて成立する配点ではありません。それでも後回しにされやすいのは、勉強しても伸びた実感がすぐ出ないからです。この記事では、リスニングの何が聞き取れていないのかを切り分けたうえで、対策本の選び方と、毎日どう回すかを整理します。

この記事の内容

  1. リスニングは直前期に伸ばせない
  2. 何が聞き取れていないのかを切り分ける
  3. 共通テスト対策本の選び分け
  4. 二次試験でリスニングが出る場合
  5. 毎日の回し方を決める

リスニングは直前期に伸ばせない

結論から書きます。リスニングは、他の分野より着手を早くすべき分野です。理由は、伸び方が階段状ではなく、なだらかだからです。

単語や文法は、覚えた瞬間に得点になります。覚えていなかった語を覚えれば、その語が出た問題は解けるようになる。因果がはっきりしています。リスニングにはこの即効性がありません。音を処理する速度が上がるまでに時間がかかり、「昨日より聞こえるようになった」という手応えがほとんど出ないまま進みます。

直前期の 1 か月で詰め込もうとすると、間に合わないか、間に合ったとしても他科目の時間を大きく奪います。1 回あたりの時間は短くていいので、早く始めて長く続けるのが、リスニングだけに当てはまる特殊な運用です。

読み上げ回数の違い

共通テストのリスニングは、大問によって音声の読み上げ回数が違います。前半は 2 回流れますが、後半は 1 回しか流れません。1 回で取り切る練習をしていないと、後半で崩れます。問題集を解くときも、最初から本番と同じ回数で解いてください。

何が聞き取れていないのかを切り分ける

「リスニングが苦手」は症状であって原因ではありません。対策本を選ぶ前に、次のどれで詰まっているかを判定してください。スクリプト（音声の文字起こし）を見れば数分で分かります。

  • スクリプトを読めば全部分かる。 原因は音です。文字と音が結びついていないので、音声の変化（つながる音・消える音）を扱う本から入ります。
  • スクリプトを読んでも意味が取れない箇所がある。 原因は語彙か構文です。リスニングの本ではなく、単語帳と解釈の本に戻ってください。ここを飛ばして音の練習をしても点は動きません。
  • 読めば分かるし、聞けば分かるが、設問に答えられない。 原因は処理の順番です。設問を先に見る、メモの取り方を決めるといった解き方の問題なので、講義型の対策本が効きます。
  • 最初は聞けるが、途中で置いていかれる。 原因は持久力です。短い音声で満足せず、長めの音源を通しで聞く練習に切り替えます。

この切り分けをしないまま問題集を買うのが、最も多い失敗です。語彙が原因の人が音の本を買っても、聞こえるようになった音が意味に変わりません。

共通テスト対策本の選び分け

選び方の目安です。

  • 音の段階でつまずいている → ゼロから英語リスニング。文字と音のずれを埋めるところから始まります。
  • 短期間で形式に慣れたい → 共通テスト英語〔リスニング〕集中講義。要点を絞ってあるので、他科目に時間を取られている人向きです。
  • 講義でじっくり固めたい → きめる!共通テスト英語リスニングまたは竹岡の共テ英語リスニング。解き方の手順まで踏み込みます。
  • すでに 8 割前後は取れていて、そこから上を狙う → 共テ英語〔リスニング〕満点のコツ。取りこぼす設問の型を潰す本です。

講義型を 1 冊終えたら、あとは本番形式の演習を切らさないことが対策のすべてになります。予備校各社の実戦問題集と過去問を、週に何回と決めて回してください。

二次試験でリスニングが出る場合

東大や一橋大など、二次試験でもリスニングを課す大学があります。この場合、共通テスト用の対策では足りません。音声が長く、選択肢の英文も難しく、メモを取りながら聞く前提の設計になっているためです。

進め方は、共通テストレベルで安定してから移るのが原則です。共通テストで取りこぼしがある状態で長文リスニングに入っても、聞けない時間が長くなるだけで練習になりません。

志望校のリスニングの有無と形式は、志望校から探すの大学別ページで確認できます。出ない大学を受けるなら、共通テスト形式だけで打ち切って構いません。

毎日の回し方を決める

リスニングは、まとまった時間を取るより、短時間を毎日のほうが結果が出ます。実務的には次のように組み立てます。

  • 問題を解く時間と、聞き込む時間を分ける。 解いて丸をつけるだけでは音の処理速度は上がりません。答え合わせのあとにスクリプトを見ながらもう一度聞き、見ないでもう一度聞く。ここが本体です。
  • 移動時間を音源の再生に充てる。 一度解いた問題の音声を繰り返し聞くだけでいいので、机の前でなくても進みます。
  • 単語帳の音声を使う。 単語帳に付属する音声を、単語を見ながらではなく、聞いて意味が出るかで確認する使い方に変えると、リスニングの下地を兼ねられます。

新しい音源を次々に増やす必要はありません。同じ音源を、聞き取れない箇所がなくなるまで回すほうが効きます。聞き流しは、すでに聞き取れる音源に対してのみ意味があります。

リスニングを英語のルートに組み込む

リスニングは単独で進める分野ではなく、単語と解釈が一定まで来たところで毎日の枠に差し込む分野です。志望校を選ぶと、並行して進める本まで含めた並びが出ます。
